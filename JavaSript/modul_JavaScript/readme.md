# Підсумкова модульна робота з JavaScript

У цьому репозиторії я зібрала рішення чотирьох практичних завдань з курсу основ програмування мовою JavaScript. Логіка прикладів адаптована під систему обліку готелю.

## Опис завдань

### Завдання 1 - Функція аналізу масиву чисел (task1.js)
- Написано функцію summarizeNumbers для збору статистики числових даних.
- Обчислення виконані через цикл for of без використання методів вищого порядку.
- Додано обробку ситуації з порожнім масивом.

### Завдання 2 - Робота з методами вищого порядку (task2.js)
- Реалізовано функцію processProducts для обробки масиву послуг.
- Застосовано вбудовані методи filter, map та reduce.
- Пошук мінімальної ціни серед наявних послуг виконано через базовий цикл після фільтрації.

### Завдання 3 - Асинхронний API-клієнт із замиканням (task3.js)
- Створено функцію createApiClient, яка використовує замикання для збереження лічильника запитів.
- Запити до сервера здійснюються асинхронно за допомогою async / await.
- Додано обробку помилок мережі через конструкцію try catch.

### Завдання 4 - Класи, ООП та DOM (task4.html, task4.js)
- Написано класи Task та TodoList для управління чек-листом підготовки номерів.
- Роботу розділено на два файли - структуру сторінки винесено в HTML, а логіку в JS.
- Реалізовано динамічний вивід елементів та роботу кнопок "Виконано" і "Видалити".
- Застосовано делегування подій - один обробник встановлено на батьківський тег списку замість створення окремих слухачів для кожного завдання.

### Для завдання 4
