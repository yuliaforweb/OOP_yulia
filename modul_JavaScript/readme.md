# Модульна контрольна робота - JavaScript

Репозиторій містить практичні завдання з курсу основи програмування мовою JavaScript. Логіка прикладів адаптована під сутності системи обліку готелю.

## Короткий опис завдань

- **Завдання 1 (`task1.js`):** Функція аналізу масиву чисел `summarizeNumbers`. Обчислення виконані через цикл for...of без методів вищого порядку. Реалізовано перевірку на порожній масив.
- **Завдання 2 (`task2.js`):** Функція обробки масиву послуг `processProducts`. Використано методи filter, map та reduce. Пошук мінімальної ціни виконано вручну після фільтрації.
- **Завдання 3 (`task3.js`):** Функція `createApiClient` із використанням замикання для лічильника запитів. Оброблено помилки через try...catch та реалізовано асинхронні запити.
- **Завдання 4 (`task4.js`):** Класи Task та TodoList для управління списком задач. Реалізовано динамічний вивід елементів та делегування подій на рівні обробника ul.

## Як запустити

### Спосіб 1. Через Node.js (локально)
Відкрити термінал у папці з файлами та виконати команду:
node назва_файлу.js

### Спосіб 2. Через консоль браузера
1. Відкрити будь-яку сторінку в браузері (наприклад, google.com).
2. Натиснути F12, перейти в девелоперську консоль (Console).
3. Скопіювати потрібний код із файлу та натиснути Enter.
