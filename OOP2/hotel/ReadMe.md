1. Налаштування бази даних PostgreSQL
   Встановити PostgreSQL 18 для Windows на компютер. https://www.enterprisedb.com/downloads/postgres-postgresql-downloads

Під час інсталяції обов'язково вказати пароль суперкористувача postgres як root.

Більше в pgAdmin чи консолі бази даних нічого робити не потрібно. Не треба створювати базу чи писати SQL-запити.

2. Підготовка папки з кодом
   Перенести очищену папку з файлами додатка на новий компютер.

Переконатися, що в папці є директорія bin, де лежать файли динамічних бібліотек dll (libpq.dll, libcrypto-3-x64.dll, libssl-3-x64.dll тощо).

3. Перший запуск у середовищі CLion
   Переконатися, що новий компютер підключений до інтернету. Це необхідно суто при першому відкритті додатка.

Відкрити папку з кодом у CLion як CMake-проєкт.

Інструмент FetchContent у CMakeLists.txt сам автоматично звернеться до GitHub, викачає офіційний репозиторій GLFW 3.4 і скомпілює його під поточну операційну систему.

Якщо кеш не оновився сам, вибрати у верхньому меню Tools - CMake - Reload CMake Project.

4. Запуск сервера та клієнта
   У правому верхньому кутку CLion вибрати таргет hotel_server і натиснути кнопку Run (зелений трикутник).

Сервер при першому старті запустить db_initializer, підключиться до дефолтної бази, перевірить наявність hotel_db, сам її створить, розгорне схему з чотирьох таблиць та закине туди стартові дані кімнат і паролі ролей. Після цього він почне слухати порт 8888.

При всіх наступних запусках сервер буде бачити, що база вже є, і відразу переходитиме до роботи без зайвих перевірок.

Вибрати таргет hotel_client і запустити графічний додаток. На екрані з'явиться відцентроване вікно входу без зайвих рамок і смуг прокрутки.

Для перевірки сайту для гостей відкрити будь-який браузер і перейти за адресою http://localhost:8888. Вкладки, перевірка скасування броні працюватимуть коректно.
